## 범위 결정

처음 계획은 A·B 각 14장(01–14)이었다. codex 사용 한도 때문에 범위를 줄였다.

- **01–10은 이미지 대신 Storybook 비교 화면으로 본다.** `Mockups/Flex` 아래 38개 컴포넌트가 현재·A·B 세 열로 렌더된다. 실제 DDS 컴포넌트라 이미지보다 정확하다.
- **11–14(새 종류·모바일 폼·모바일 흐름·다크)만 A·B 모두 이미지로 만든다.** Storybook 프로토타입만으로는 완성된 외관을 보기 어려운 영역이다.
- 01–10 중 한도 전에 이미 나온 보드는 버리지 않고 남겼다.

## 기록

- [records-a-11-14.json](a/records-a-11-14.json): A 11·11-v2·12·13·14. 11–13의 프롬프트는 먼저 멈춘 워커의 세션 기록에서 복원했다.
- [records-b-11-14.json](b/records-b-11-14.json): B 11–14. B 11 항목의 sha256은 채택본 `11-new-kinds-v2.png`의 값이다(파일 칸은 원본 이름).
- 기록의 `profilesSha256`·`briefSha256`는 생성 시점 값이다. 이후 Gemini 검토를 반영하며 두 파일이 바뀌었다(교차 배율 값 C 강등, B 선택 패널 12, `touch-target` 추가, 치수표 재생성). 이미지는 그 이전 치수로 그렸다.
- 01–10 범위 밖 보드(A 06·07·08, B 01·02·06)는 기록 파일이 없다. 위 표가 출처 기록이다.
- 원래 B 보드 10장은 [2026-10-09-flex-all-components](../2026-10-09-flex-all-components/README.md)에 그대로 있다. 근사 hex(#262A2D 등)를 썼다는 점이 이번 보강과 다르다.
