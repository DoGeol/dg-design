# 사용 가이드 스킬 (2026-10-09)

> 상태: 활성 · **구현 전**. 관련: [flex 적용 방향](2026-10-09-flex-adoption-direction.md)

## 결정

dg-design을 쓰는 규칙은 문서가 아니라 **컴포넌트별 사용 예제를 담은 에이전트 스킬**로 전달한다.

| 항목 | 결정 |
| --- | --- |
| 소유 | dg-design이 정본을 관리한다. 특정 소비 앱(dg-studio 등)에 묶이지 않고 어느 프로젝트에서든 쓸 수 있어야 한다 |
| 예제 | dg-design 저장소에서 새로 쓴다. 도메인 데이터·앱 라우팅·앱 브랜드 덮어쓰기를 가정하지 않는 중립 예제다. dg-studio의 기존 예제(38종·151개)는 참고 재료일 뿐 이관 대상이 아니다 |
| 형태 | `SKILL.md` 하나 + 컴포넌트별 참조 파일. `SKILL.md`에는 언제 쓰는지, import·tokens.css 로드 규칙, layout 최소 권장사항, 컴포넌트 목록만 둔다. 컴포넌트 파일(목적·쓰지 말 때·핵심 API·예제·접근성 주의)은 필요할 때만 읽힌다 |
| 검증 | 예제는 실제 `.tsx`로 두고 dg-design 타입 검사에 포함한다. API가 바뀌면 예제가 빌드에서 깨진다. 컴포넌트 참조 파일은 예제에서 생성한다 |
| 배포 | npm 패키지에 스킬 폴더와 **에이전트용 설정 가이드 md**를 함께 넣는다. 패키지 설치만으로는 스킬이 설치되지 않는다. 사용자는 에이전트에게 "설치된 dg-design의 설정 가이드를 읽고 스킬을 구성해줘"라고 요청하거나 가이드의 명령을 직접 따른다 |
| 설정 가이드 내용 | ① 스킬이 무엇이고 패키지 안 어디에 있는지 ② 에이전트별 연결 방법(Claude Code `.claude/skills/`, Codex `.agents/skills/`, 그 밖의 에이전트는 규칙 파일에서 참조) ③ 기본은 심링크(패키지를 올리면 스킬도 따라 올라감), 심링크가 곤란하면 복사 + 버전 표기 ④ 프로젝트의 layout 규칙을 사용자에게 물어 **별도 로컬 파일**에 적기(패키지 스킬은 고치지 않음) ⑤ 연결 확인 방법과 패키지 업그레이드 때 할 일 |
| layout | 프로젝트마다 다르므로 최소 권장사항만 정한다. 페이지 구조(헤더·사이드바·그리드)는 프로젝트 소유다 |

## layout 최소 권장사항(초안)

[flex 적용 방향](2026-10-09-flex-adoption-direction.md)과 [이중검토 합의](../reports/flex-adoption-review/review/synthesis.md)에서 확정된 것만 담는다.

- 간격은 px 대신 역할 토큰(필드 간격·묶음 간격·페이지 여백)으로 쓴다.
- 입력은 외부 라벨 outline이 기본이다. box·속성 행·line은 모바일 상세 화면에서만 쓴다. box에도 입력 경계를 지우지 않는다.
- 한 화면의 주 행동(brand solid)은 하나다.
- 모바일 조작 영역 44px 이상, 데스크톱 단독 조작 대상 24px 이상.
- 밀도(desktop/mobile)는 앱 루트에서 명시적으로 고른다. 화면 폭으로 자동 전환하지 않는다.
- 목록 행 안에 버튼·링크를 중첩하지 않는다. 행의 주 행동과 끝 메뉴를 나눈다.
- 부유 패널 1px 경계, Sheet 모서리 없음 같은 외관은 컴포넌트 기본값이 맡으므로 소비자가 덮어쓰지 않는다.

## 검토하고 고르지 않은 안

- **dg-studio 예제를 정본으로 유지·생성**: 앱이 쓰는 패키지 버전과 앱 도메인에 묶여 다른 프로젝트에서 그대로 쓸 수 없다.
- **사람용 문서 사이트만 제공**: 이 생태계의 주 사용자는 코딩 에이전트다. 따라 쓸 수 있는 예제가 설명 문서보다 사용 코드를 직접 바꾼다.
- **설치 스크립트(postinstall)로 자동 연결**: 설치만으로 다른 프로젝트의 폴더를 바꾸는 부작용이 있고, pnpm은 기본적으로 설치 스크립트를 막는다. 에이전트마다 위치도 달라 한 스크립트로 맞추기 어렵다.
- **스킬 폴더만 넣고 연결은 README 한 줄로 안내**: 처음 판의 결정이었다. 연결을 누가 하는지가 비어 있고, 프로젝트별 layout 규칙을 담을 자리가 없었다(2026-10-09 사용자 지적으로 바꿈).
- **layout 프리셋을 패키지에 고정**: 프로젝트마다 페이지 구조가 달라 강제하면 우회 코드가 늘어난다. 반복이 확인된 조합만 [구성 규칙](2026-09-05-component-composition-rules.md)대로 승격한다.
