## 목표

앱과 DDS 내부가 같은 24 grid 도형·선 굵기·접근 이름 규칙을 사용한다.
아이콘 자체는 행동을 소유하지 않고 Button·링크·선택 표시 안에 들어간다.
첫 공개 세트는 16종으로 제한하며 필요한 아이콘만 번들에 남게 한다.

## API

```tsx
import { ChevronDownIcon, CopyIcon, SunIcon } from "@dg-design/react/icon";
import { Button } from "@dg-design/react/button";

export function IconExamples() {
  return (
    <>
      <Button iconOnly aria-label="코드 복사" intent="neutral" variant="ghost">
        <CopyIcon size={20} />
      </Button>
      <span><SunIcon size={16} /> 라이트 테마</span>
      <ChevronDownIcon size={24} label="아래 방향" />
    </>
  );
}
```

| API | 기본안 |
| --- | --- |
| 공통 `IconProps` | `size?: 16 \| 20 \| 24`, `label?: string`, `className`, `style`, SVG ref |
| 기본 크기 | 20; width·height가 같은 정사각형, `viewBox="0 0 24 24"` |
| 이름 | 의미를 나타내는 PascalCase + `Icon`, 방향은 Up/Down/Left/Right |
| 색 | `currentColor`; 의미 색은 부모의 semantic foreground로 지정 |
| 접근 이름 | 비어 있지 않은 label이면 `role="img"` + `aria-label` |
| 장식 | label 생략/공백이면 `aria-hidden="true"`, `focusable="false"` |

공개 export는 아래 이름으로 고정하는 기본안이다.

```tsx
// @dg-design/react/icon의 named exports, default export·아이콘 registry 없음
ChevronUpIcon; ChevronDownIcon; ChevronLeftIcon; ChevronRightIcon;
CloseIcon; MenuIcon; ExternalLinkIcon; PlusIcon; MinusIcon;
SunIcon; MoonIcon; DragHandleIcon; CheckIcon; CopyIcon; SearchIcon; SettingsIcon;
// 타입: IconProps
```

- 각 아이콘은 별도 모듈, `icon/Icon.ts`가 named re-export를 제공한다.
- 공통 껍데기는 공개하지 않으며 `<Icon name="...">` 런타임 맵을 만들지 않는다.
- `forwardRef<SVGSVGElement>`를 지원한다. 도형을 덮는 children은 받지 않는다.
- `viewBox`·strokeWidth·fill·role·tabIndex·직접 aria 이름은 공통 계약이 소유한다.
- 네이티브 SVG 속성 확장 시 위 예약 속성과 이벤트 핸들러를 타입에서 제외한다.
- `className`·`style`은 소비자 외관 조정에 남긴다. size prop의 선택지는 늘리지 않는다.
- 트리 셰이킹은 설계 기대다. 한 아이콘만 import한 실제 번들 검사로 합격 판정한다.

## 도형·토큰

| 역할 | 기본안 | 적용 |
| --- | --- | --- |
| grid | 24×24 | 모든 도형의 고정 좌표계 |
| 크기 | 기존 `--dds-dimension-x4`, `x5`, `x6` | 16·20·24 |
| 선 굵기 | **신규 `--dds-stroke-icon-width: 2`** | unitless SVG 사용자 좌표 단위 |
| 선 끝·꺾임 | round | 세트 전체 고정 |
| 색 | currentColor | 부모 `--dds-color-fg-*` 상속 |

- stroke는 크기에 비례해 축소된다. 16px에서 2 CSS px 고정 굵기로 만들지 않는다.
- `vector-effect="non-scaling-stroke"`는 쓰지 않는 기본안이다.
- 신규 stroke 역할은 생성기·타입·테마 가드·공개 토큰 문서에 함께 연결한다.
- 기존 `roles`에는 stroke 그룹이 없으므로 방출 경로를 구현에서 추가·검증해야 한다.
- 색 토큰은 추가하지 않는다. tokens.css 로드는 계속 소비자 책임이다.
- DragHandle의 점 등 채움 도형은 currentColor이며 외곽 stroke를 중복해서 그리지 않는다.
- CSS는 `@layer dds`. 다크/라이트에서 도형은 같고 상속 색만 바뀐다.

## 상태 축과 접근성 계약

| 상태 | Icon 책임 | 부모 책임 |
| --- | --- | --- |
| default | 크기·도형·상속 색 | 의미 있는 문맥/버튼 이름 |
| hover·pressed | 자체 상태 없음 | Button·링크 색과 표면 |
| focus-visible | 자체 탭 정지점 없음 | 조작 요소의 2px 링 |
| selected | Check 등을 장식으로 제공 | aria-pressed/checked/current와 선택 규칙 |
| disabled | 상속 색 유지 | 비활성 의미·이벤트 차단·fg-disabled |
| label 있음 | img 이름 노출 | 같은 의미의 문구와 중복 낭독 방지 |

- 아이콘만 있는 Button은 Button에 접근 이름을 준다. 내부 Icon에는 label을 주지 않는다.
- label을 주더라도 클릭·키보드 행동을 추가하지 않는다.
- 하나의 SVG 안에 title id를 만들지 않는 기본안이라 SSR id 충돌 경로가 없다.
- 색으로만 중요한 상태를 표현하지 않는다. 체크 도형과 부모 ARIA를 함께 쓴다.
- label 생략 시 스크린리더 접근 트리에 장식 아이콘이 나오지 않아야 한다.

## 모바일 밀도

- Icon은 16·20·24 시각 크기를 밀도에 따라 자동 변경하지 않는다.
- 최소 조작 영역은 부모가 제공한다: DDS 모바일 밀도 44, 데스크톱 24.
- 앱의 화면별 44px 확장은 유지한다. dg-studio에 밀도 속성을 새로 도입하지 않는다.
- 작은 내부 mark(12·14)는 B1b에서 기존 CSS 배치 크기를 보존해 SVG만 바꾼다.
- 16부터 시작하는 공개 size 축과 내부 CSS 축소를 구분해 문서화한다.

## 구현 묶음과 호환성

- **B1a**: icon 모듈·CSS·하위 경로, 테스트·스토리·skill 예제·stroke 토큰·changeset.
- **B1b**: chevron/check/indicator 인라인 SVG 교체, 기존 role·클래스·이벤트·선택 상태 유지.
- 확인된 대상: `select/Select.tsx`, `multi-select/multi-select-option.tsx`, `multi-select/multi-select-search.tsx`.
- 추가 대상: `list/list-section.tsx`, `dropdown-menu/menu-choice-items.tsx`, `checkbox/Checkbox.tsx`, `chip/Chip.tsx`.
- Close는 Chip 등 같은 파일을 건드릴 때 함께 교체할지 B1b 계획에서 명시한다.
- 메뉴 radio indicator는 현재 채운 원이다. Check로 바꾸면 구분 의미가 달라지므로 금지한다.
- 기본안은 IconBase를 쓰는 **비공개 DotIcon**으로 원을 옮겨 공개 16종은 유지한다.
- `internal/use-selection-indicator.ts`의 움직이는 밑줄/표면은 SVG가 아니므로 교체하지 않는다.
- B1b는 B3·B5 뒤 별 PR. 바뀐 모든 상태 매트릭스를 CI에서 재생성한다.

- `packages/react/skill-src/icon.tsx`: 장식/설명용/이름 있는 Button 조합의 중립 예제.
- 첫 세트 표, size, label, currentColor, 부모 조작 영역 규칙을 예제 주석에 설명한다.

- 새 토큰을 읽는 react/tokens 버전 짝은 실제 릴리스 버전으로 customization에 기록한다.
